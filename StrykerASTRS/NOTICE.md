Stryker TFAR Setter

This addon packages and lightly adapts ASTRS - A Simple TFAR Radio System for
the Stryker mod.

Original project:
https://github.com/chatterchats/ASTRS

Original authors:
Chatter and M3ales

License:
MIT. See LICENSE in this folder.

Stryker changes:
- Renamed the addon class to StrykerASTRS to avoid conflicts with standalone ASTRS.
- Kept the TFAR beta-compatible tfar_core dependency instead of task_force_radio.
- Updated metadata for Stryker packaging.
